# 组件落实与验收

按任务挑选组件，不把下表变成每页必须完成的清单。

## 组件配方

| 组件 | 结构与风格 | 必须保留的功能 |
| --- | --- | --- |
| 导航轨 | 直线边界、短标签、当前项色块；编号需有实际顺序 | 当前页 `aria-current`；窄屏横向/展开导航，不只剩猜测性图标 |
| 标题区 | 一个强标题，旁边仅放有用的计数、范围或主动作 | 语义标题；装饰底字隐藏于辅助技术，不重复朗读 |
| 工具栏 | 按对象与频率分组，像可取用的附件位 | 可见标签、实际结果、清除方法；窄屏换行/折叠次要工具 |
| 列表/表格 | 共享列基准线、细分隔、选中行侧色条 | 真表格用 table；行导航用链接，选择用按钮/勾选 |
| 详情模块 | 边界对应选中对象；标题、元数据、动作分区 | 空选择提示、关闭/返回；窄屏内联或抽屉可达，不直接隐藏 |
| 表单 | 平面输入框、较实边界、聚焦轮廓、简洁分组 | label、帮助/错误关联、单位；不只用 placeholder |
| 主动作 | 实体强调底 + 深色字，少量切角 | hover/active/focus/disabled；触控不依赖 hover |
| 状态 | 小矩形块，文字 + 符号或形状 | Ready / Error 等真实状态，不只用彩色点 |
| 进度 | 已知进度或简单活动标记 | 对应真实过程；未知进度不伪造百分比 |

不要让非交互卡片带按钮式 hover，也不要用伪元素画看起来可点击却不能用的控件。

## CSS 与状态

采用语义 token：`canvas / surface / ink / muted / line / control-line / accent / on-accent / focus / danger`。沿用项目现有 CSS variables、Tailwind theme 或组件 token，不并行维护同义体系。

参考 [../assets/tokens.css](../assets/tokens.css)。只用某个方向就裁去另两套；实际产品不必为了展示皮肤而新增主题切换。

切角按钮用不被裁切的外层承接焦点，内层负责形状：

```html
<button class="action"><span>Open project</span></button>
```

```css
.action { border: 0; padding: 0; background: transparent; color: var(--on-accent); }
.action > span {
  display: block; padding: .8rem 1.2rem; background: var(--accent);
  clip-path: polygon(0 0,100% 0,100% calc(100% - 8px),calc(100% - 8px) 100%,0 100%);
}
.action:focus-visible { outline: 2px solid var(--focus); outline-offset: 3px; }
```

不要在 button 外层或所有祖先统一 `overflow:hidden`。有菜单、提示框或焦点时检查实际溢出路径。装饰层 `pointer-events:none`。

纹理放在独立背景/伪元素，避免祖先 opacity 使正文变淡。必要时直接去掉图案；不把 Canvas/WebGL 当成普通网格的前提。若任务要求深浅主题，分别检查状态和图像；Archive 与 Field 是方向，不意味着所有页面都要切换。

## 宽屏到窄屏

断点由内容的最小可用宽度决定。示例约 900px 收起侧向布局、约 600px 简化密度，可改。不要用绝对定位固定整张桌面海报。

1. 保持主任务顺序：标题 → 主要操作/筛选 → 内容 → 当前对象详情。
2. 竖轨变横条/菜单；必要操作和当前状态保留可见文字。
3. 详情改内联、独立页或可关闭抽屉；若用模态抽屉，处理焦点进入、返回和 Escape。
4. 短列表可堆叠，真宽表格可局部横滚并保留标题关联；不要全站横向溢出。
5. 标题缩放且自然换行，不缩小正文或整个桌面画布。
6. 先减少纹理、边栏装饰和底字，再减少功能内容。

## 按实际需要验证

- 用正常/长标题、多行描述与空结果检查。确认过滤、选择、详情等主行为工作。
- 检查一组宽屏和约 390px 窄屏，无页面横向溢出；窄屏能完成主任务。必要时补查失效的中间宽度。
- 键盘走通主路径，观察焦点，确认切角、固定栏和滚动容器没有遮挡。
- 检查文字与控件对比度；浅底强调文字不直接用黄；选中和错误有非颜色线索。
- 模拟减少动态效果，没有依赖持续动画传递的信息。
- 对实际存在的远程请求、提交或批量操作检查加载/失败/重试/禁用；静态展示不必新增后台流程。
- 最后检查可见文案：删除重复标题、装饰英文、无意义编号和实现说明。新文案默认英文，明确指定时换语言。

按项目要求运行已有检查。样式调整不制造仅断言 CSS 字面值的测试；有逻辑变更验证行为。使用可用浏览器工具做截图检查，未执行的验证写明，不能把静态阅读说成运行通过。
