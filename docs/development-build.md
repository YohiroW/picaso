## 实测

- **真实请求**。0.1.1 通过界面显式选用环境变量。生成一次项目图标；退出重开，从历史原图加入编辑草稿，再以 ⌘↩ 提交一次修改。两次均成功，原生保存面板导出的编辑版 PNG 与图库哈希一致。这张图用于 0.1.2 的 Dock 和窗口图标。[模型、参数与用量](openai-provider.md)
- **覆盖安装**。只读挂载已通过校验的 DMG，核对 Applications 快捷方式，从映像替换用户 Applications 内的 0.1.1。验证安装副本签名、arm64 架构，以及打包 ICNS 与已检查的项目图标完全一致。
- **数据**。对升级前后完整任务行、图片 ID、父图引用、PNG SHA-256 和所选密钥来源做逐项比较。2 条成功任务、2 张 PNG、1 条编辑引用均一致。SQLite 完整性与外键检查通过。安装副本及 Picaso 数据目录均未检出环境变量密钥值。
- **启动和离线**。从 Finder 启动已安装副本可以查看两张历史图；本机 Finder 进程没有继承终端的环境密钥。另以移除该环境变量、禁止进程 IP 出站连接的配置启动，验证两张预览、键盘选图、中文草稿和来源修复提示。此时提交按钮禁用。退出后再次比对，任务、引用及原图仍与升级前一致。

## 自动化

Rust 14 项测试覆盖钥匙串真实读写（隔离条目、虚构密钥）、来源选择和修复、本地 HTTP 协议与错误映射、写盘失败、任务并发去重、图库版本、编辑输入以及退出恢复。模拟中断后重新打开图库，运行中任务标记为结果未确认，清理未提交的临时文件与孤立原图，保留已完成原图和任务，不重新请求服务商。

Vitest 5 项覆盖密钥引导、选图不提交、草稿保留、模型能力和中文输入法组合事件。已通过 TypeScript 检查、Rust 格式检查、Clippy 及 Apple Silicon release 打包。中文输入法组合使用事件测试；最低系统版本和其他 Mac 尚未做实机验证。
